## Браузерная версия

Попытка обновления до Playwright 1.63.0 не дала установить соответствующий Chromium: загрузка возвращала некорректный архив. Для воспроизводимой проверки сохранён исходный pin 1.51.0; браузер загрузился с резервного официального зеркала. Это старая версия. Перед использованием личных аккаунтов обновите Playwright/Chromium в своей среде и повторите тесты:

```powershell
python -m pip install --upgrade playwright
python -m playwright install chromium
python -m unittest discover -s tests -v
```

Результаты локальных тестов подтверждают работу компонентов, но не заменяют проверку выполнения задания живой моделью.
