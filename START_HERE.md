# Обновление 0.9.1 — диагностика ModelRun HTTP 400

Остановите агент через Ctrl+C. Замените всю папку agent из архива, сохранив свои .env,
.venv и .profile. Перезапустите тем же Python, которым запускали 0.9.

```powershell
python -m agent.cli --url http://127.0.0.1:8765
```

Попросите: «Проверь фактический список и заполненное поле. Продолжи предыдущую задачу:
добавь только отсутствующие задачи — подготовить отчёт, проверить договор, отправить
результат. Отметь подготовку отчёта выполненной. Проверь три задачи и одну завершённую».
Если HTTP 400 повторится, скопируйте сообщение с Detail/error_type, предварительно
проверив, что там нет личных данных. Эта версия не обещает устранения причины HTTP 400:
она извлекает описание отказа, которое предыдущая версия скрывала.

# Обновление до 0.9

Остановите агента через Ctrl+C. Из архива замените **всю папку agent** в вашем проекте.
Сохраните свои `.env`, `.venv`, `.profile`. Повторная настройка API не требуется.
Должен появиться баннер BROWSER AGENT / 0.9.

При уже запущенном демо-сервере:

```powershell
python -m agent.cli --url http://127.0.0.1:8765
```

Если используете виртуальное окружение, запускайте через его Python:

```powershell
.\.venv\Scripts\python.exe -m agent.cli --url http://127.0.0.1:8765
```

В задаче укажите: сначала проверить уже созданные задачи, добавить только отсутствующие,
отметить подготовку отчёта выполненной и проверить итог. Это предотвращает слепое
повторение действий предыдущего запуска.

# OpenRouter — запуск в PyCharm

1. Распакуйте архив в новую папку. Откройте в PyCharm папку `browser-agent`, содержащую `agent` и `requirements.txt`.
2. Используйте своё рабочее виртуальное окружение или создайте новое. Не пересоздавайте активную `.venv`.
3. В терминале с активным окружением выполните:

```powershell
python -m pip install -r requirements.txt
python -m playwright install chromium
python -m agent.cli --setup
```

В мастере введите **новый** ключ OpenRouter (ввод скрыт). Скомпрометированный ключ отзовите.
Оставьте скриншоты включёнными. При выборе модели нажмите Enter для `openrouter/free`
или введите номер конкретной бесплатной модели из полученного каталога.
Старый ID Qwen будет заменён. API-ключи в архив не включены.

```powershell
python -m agent.cli --check
python -m agent.cli
```

`--check` делает два тестовых обращения к модели и расходует квоту.
После `Вы ›` пишите задачи обычным текстом. Браузер остаётся открыт между сообщениями.
`/reload` перечитывает настройки, `/check` проверяет API, `/retry` продолжает задачу,
`/new` очищает память, `/exit` закрывает браузер.

Для демо запустите в отдельном терминале:

```powershell
python -m http.server 8765 --directory demo
```

Основной терминал:

```powershell
python -m agent.cli --url http://127.0.0.1:8765 --record
```

429 означает ограничение сервиса. Новый код распознаёт известные причины и учитывает
Retry-After, но не отменяет квоты. Если ошибка остаётся, пришлите текст ошибки без ключей.
Успешный тест подключения ещё не означает успешного выполнения задачи в браузере.
